# 🔬 Détection de Maladies de Peau avec YOLO

Une application Streamlit pour détecter les maladies de peau en utilisant YOLOv8.

## 🚀 Déploiement Streamlit

L'application est prête à être déployée sur [Streamlit Cloud](https://streamlit.io/cloud).

### URL du fichier app.py:
```
https://github.com/mamediarraStci2/Detection-skin-disease-yolo/blob/main/app.py
```

## 📋 Prérequis

- Python 3.8+
- Les dépendances listées dans `requirements.txt`

## 🛠️ Installation locale

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 📦 Dépendances

- ultralytics >= 8.0.0
- streamlit >= 1.28.0
- Pillow >= 9.0.0
- opencv-python-headless >= 4.8.0
- numpy >= 1.24.0
- pandas >= 2.0.0
